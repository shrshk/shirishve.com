# Credits

No painting is reproduced on this site. Every brush stroke is drawn by the code in `src/lib/brush.ts`
(at build time) and `src/lib/sky.ts` (in the browser). The grain texture in `public/textures` is
original and generated by an SVG filter.

## Fonts

Self-hosted from `public/fonts`, Latin subset, all under the SIL Open Font License 1.1.

| Font           | Used for       | Source                                       |
| -------------- | -------------- | -------------------------------------------- |
| Fraunces       | Display        | https://github.com/undercasetype/Fraunces    |
| Newsreader     | Body           | https://github.com/productiontype/Newsreader |
| Caveat         | Margin notes   | https://github.com/googlefonts/caveat        |
| JetBrains Mono | Code and stats | https://github.com/JetBrains/JetBrainsMono   |
| Patrick Hand   | Notebook pages | https://github.com/googlefonts/patrick-hand  |

The WOFF2 files were taken from the Fontsource packages of each font.

## Icons

Brand icons are from Simple Icons (https://simpleicons.org, CC0 1.0), unmodified. Each brand's
trademark belongs to its owner. A platform that Simple Icons does not carry gets a plain letter.

## Club

Arsenal is shown through red and white, original drawing and words only. No crest, wordmark, kit or
sponsor mark is used. This site has no connection to the club.
